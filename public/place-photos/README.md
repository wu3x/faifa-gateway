# صور الأماكن — موقع فيفاء

ضع الصور مباشرة داخل هذا المجلد. لا تحتاج تعديل أي كود أو ملف فهرس.

## تسمية الصور
استخدم **الاسم العربي الموجود على البطاقة** متبوعًا برقم اختياري:
- `منتزه وإطلالة الخطم1.jpg`
- `منتزه وإطلالة الخطم2.jpg`
- `ممشى البن الخولاني1.webp`
- `ممشى البن الخولاني2.png`
- `مقهى جارة الغيم.jpg`

يدعم JPG/JPEG وPNG وWebP وAVIF. يدعم الأرقام العربية والإنجليزية، والمسافات والشرطات السفلية قبل الرقم، واختلاف الهمزات والتشكيل والتاء المربوطة. إذا كان اسم البطاقة يحتوي ترجمة إنجليزية بعد شرطة، استخدم الاسم العربي فقط.

## طريقة العمل
- أثناء بناء الموقع، يقرأ Vite جميع الصور في هذا المجلد ويُنشئ فهرسًا تلقائيًا.
- تظهر حتى 3 صور لكل بطاقة، حسب الترتيب الرقمي.
- أثناء لمس البطاقة والتمرير على الجوال تظهر الصور من أعلى؛ وعند رفع الإصبع تختفي.
- لا يمكن النقر على الصور، ولا يتأثر التصويت أو روابط المكان.
- لا تظهر صور للبطاقات التي لا تملك ملفات مطابقة.
- بعد رفع الصور إلى GitHub، انتظر نجاح GitHub Actions حتى تظهر.
- أضف صورًا تملك حق نشرها فقط. لا تستخدم أسماء ملفات متطابقة بأرقام متكررة.

**مهم:** لا يكتشف المتصفح ملفات جديدة قبل إعادة بناء الموقع. يجب رفع الصور إلى هذا المجلد داخل المستودع، وليس إلى مجلد آخر.
