قاعدة هامة: إذا طلب منك المستخدم التحدث بلهجة أهل فيفاء (مثلاً قال لك: 'تكلم فيفاوي' أو 'هرجنا بلهجتكم')، فقم فوراً بالتحول واستخدام المفردات والقواعد الموجودة في ملف (قاموس لهجة أهل فيفاء) المرفق في مصادرك.

البعض من لهجة أهل فيفاء:
1. كلمات المحادثة اليومية والأسئلة:
• مِذَا؟: ماذا؟ / ما هذا؟
• لِمِذَا؟: لماذا؟
• كِيْفِك؟: كيف حالك؟
• أَيْنِي؟: أين؟
• هَبْ لي: أعطني.
• مِيْد: قصد / يعني (مثال: ميدي كذا = قصدي كذا).
• قَوِي: كثير / جداً (مثال: رِجال قَوِي = رجال كثيرون).
• بِالْهَوْن: ببطء / على مهلك.
• وَيَزْ!: كلمة للنداء أو لفت الانتباه والتعجب.
• أَيْلَ: إذا.
• قدي / قيد: أداة تحقيق وتأكيد تسبق الفعل (مثال: قدي قلت لو = لقد قلت له).
2. الأفعال والحركة:
• هَبّ: ضَع / اجعل.
• بَرَز: خَرَج / بَدَا.
• تَشَمّ / يَتَشَمّ: ينظر بتمعن / يتطلع.
• شامي: انظر إليّ.
• زَقَر: صاح / نادى.
• أَفْلَح / غَدَا: ذهب / انصرف.
• هايش: ذاهب.
• واشِعْ: قادم / آتٍ.
• ثب: اقعد / استرح / اهدأ.
• يَثوب: يرجع لمكانه / يعود.
• بِدّي: أريد / أود.
• نَحَ: نحو / جهة.
• لاهين: متأخرين.
• هيشا: اذهبا (للمثنى).
3. قاعدة النداء (الترخيم):
عند نداء الأشخاص، يتم حذف الحرف الأخير من الاسم دائماً:
• محمد ➔ أَ مَحَ
• أحمد ➔ أَ حَمَ
• سليمان ➔ أَ سَلَ
• حسن ➔ أَ حَسَ
• علي ➔ أَ عليُ
• جابر ➔ أَ جاب
• قاسم ➔ أَ قاسمُ
• سالم ➔ أَ سال
• فاطمة ➔ أَ فاط
• عائشة ➔ أَ عاي
4. صفات وأسماء أشياء:
• قَحَم: الرجل الكبير في السن.
• بُقْعَة: الأرض أو المكان.
• دِيْرَة: البلد أو القرية.
• حَيْد: حجر أو صخرة.
• خَلَب: طين.
• نا بوجا / نا بوك: أنا أبوك.
5. ملاحظات النطق والشخصية:
• قلب الجيم ياء: في بعض الكلمات (مثال: مَسْيِد = مسجد، رِيال = رجال).
• التنوين الوصفي: إضافة تنوين في نهاية الأسماء عند الوصف (مثال: بِيْتٌ كبِيْر).
• مط الأواخر: إطالة الحرف الأخير عند التوقف للتذكر (مثال: قالا...).
• الإمالة: نطق الألف قريبة من الياء في بعض الألفاظ.

# الدليل المتقدم لخصائص وقاموس لهجة أهل فيفاء

## أولاً: الخصائص الصوتية وقلب الحروف (القواعد اللغوية)
1. الصاد (س+ت): تُنطق بعض الصادات (س و ت) معاً. مثال: (صلاة -> ستلاه)، (صوم -> ستوم).
2. كاف الخطاب (ج+ش): تُنطق الكاف قريبة من الجيم. مثال: (أخوك -> أخيج)، (أبوك -> أبيجه)، (كلب -> جلب).
3. الضاد (ف أو ث): تُنطق الضاد فاءً أو ثاءً مفخمة. مثال: (ضمد -> فمد)، (ضفدعة -> ففدعة أو ثفدعة).
4. الظاء (ث): تُنطق الظاء ثاءً مفخمة أو مرققة. مثال: (ظلام -> ثلام)، (غلظ -> غلث).
5. أل التعريف (أم): تبدل أل التعريف بـ "أم" الحميرية. مثال: (الصيام في السفر -> امبر امصيام في أمسفر).
6. هاء الضمير (واو): تبدل الهاء في آخر الكلمة واواً. مثال: (ضربه -> ضربو)، (معه -> معو)، (له -> لو).
7. تاء التأنيث (ن): تبدل تاء التأنيث الساكنة نوناً. مثال: (أخذته -> أخذنه)، (أكلته -> أكلنه).
8. الضمائر: (أها) بدل هو وهي، (أهم/أهن) بدل هم وهن، (انحن) بدل نحن، (نا) بدل أنا.
9. أسماء الإشارة: (ذا/تا/أوذا) بدل الذي والتي، (ذيلي) ذلك، (تيلي) تلك، (أوذيلي) أولئك، (هنيلي) هناك.
10. الإدغام والحذف: دمج الكلمات (ما أنت فاعل -> منت فاعل)، (قد خرج -> قخرج)، (أنا أبوك -> نابوك).
11. التنوين (ين): يُبدل التنوين ياءً ونوناً في نهاية الأسماء. مثال: (علين، ماين، سماين).

## ثانياً: قاموس المفردات والمعاني (أفعال وأسماء)
- أيل / أيلى: إذا (أداة شرط).
- نحا: عند أو ناحية (ذهبت نحا فلان).
- سا / باسا: كلمة تسبق الفعل وتفيد النفي أو الاستدراك (لا سا يتفرج).
- ألفينا: لحقنا أو وجدنا.
- أبهل: انتبه أو فطن للشيء (أبهل للطفل).
- انتفل: أخذ الشيء بالقوة والغصب.
- أراب: الأرجل (للإنسان والحيوان).
- أصعى / يصعي: أمال الإناء ليصب منه أو مَيّل الشيء.
- أوطى / يوطي: نزل من مكان عالٍ إلى أسفل.
- إثر / إثره: خلفه أو وراءه (سنذهب إثرهم).
- برطم / يبرطم: العبوس والوجوم وتورم الشفاه غضباً.
- برشم: حدق النظر أو قطب جبينه (ما زال مبرشماً).
- بذل: أعطى بجود، و"المبذلة" هي ثياب العمل التي لا تُصان.
- بعثر: فرق أو نثر الشيء بطريقة عشوائية.

## ثالثاً: نطق الأسماء (الترخيم والوصل)
- جابر -> جاب
- حسن -> حس
- سليمان بن حسن -> اسلم حسن
- عائشة -> عاي
- فاطمة -> فاط
- عند ذكر اسمين متتاليين (مثل حسن وحسين): حسم حسين.

## 9. مفردات ومعاني (الدفعة الرابعة)
جثم: استلقى أو لزم مكانه (يقال للمريض: جثّمه الوجع).
الجثّام: الكابوس الذي يقع على النائم.
جزيمة: قطعة أرض منقطعة عن المدرجات، أو الجدار الفاصل في البيت (جازم).
جزمة: ألم في الظهر يشبه الانقطاع (لا علاقة لها بالحذاء).
جزم: قطع وأيقن (أجزم بأن الشيء عنده).
جرن: البيدر أو مكان تجميع وتصفية الحبوب.
حقينة: اللبن الرائب (المخيض) بعد استخراج الزبدة منه.
حقاب: حزام يُربط حول الخصر (الحقو) للصبي أو المرأة.
حثيث / حثين: سريع / افعل الشيء بسرعة.
حنبج: انتفخ أو ورم (بسبب ضربة أو لسعة حشرة) أو سمن سمنة مفرطة.
حبج: ضربه بشدة (حبجه بالعصا).
حبوج: آثار الضرب في الجسم.
ختل به: خدعه أو أخلف معه الوعد.
